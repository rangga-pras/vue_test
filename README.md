# Dashboard Vue — Pertemuan 5

Output praktikum Session 5 Web Application Development.

## Menjalankan project

```bash
npm install
npm run dev
```

## Fitur sesuai materi

- Vue 3 + Vite
- Single File Component
- Props pada `UserCard.vue`
- State dengan `ref()`
- Fetch JSONPlaceholder
- Request state: loading, empty, error, success
- List rendering dengan `v-for` dan `:key="user.id"`
- Conditional rendering dengan `v-if` / `v-else-if`
- Search dengan `computed()`
- Riwayat pencarian dengan `watch()`
- Exercise A: jumlah hasil pencarian dengan `computed()`
